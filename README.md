# Repositório de velas do Deadheim

Catálogo remoto consumido pelo mod `Velas`. O arquivo `manifest.json` é a fonte
de verdade: cada entrada aponta para uma imagem em `sails/` e inclui seu SHA-256.

Os IDs publicados são persistidos nos navios e não devem ser renomeados. Novas
velas devem usar IDs únicos contendo apenas letras, números, `_` ou `-`.
